## Where things stand

**Residencies are stalled, not progressing.** Every stipend-bearing option researched so far has a
closed deadline. The only application window currently open is Palazzo Monti on 2026-09-30, and it
pays nothing. The real pipeline is the 12 unverified names in the tracker.

**The client brief has an unresolved contradiction.** He is trained in typography, but the work he
admires is sculptural and surreal. Nobody has confirmed which one he actually makes. This blocks the
residency shortlist, the fashion pitch and the signature series all at once.

**Nothing has been collected from the artist yet.** The intake checklist in the blueprint is empty.
No portfolio inventory, no pricing, no statement.
